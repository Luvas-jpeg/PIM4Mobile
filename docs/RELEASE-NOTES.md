# MediShop Aluno — demonstração acadêmica Android

Baixe `MediShop-Aluno-Android.apk` e instale em um aparelho Android. Se solicitado, permita a instalação pelo navegador ou gerenciador de arquivos utilizado.

- API: https://pim4-api-demo.onrender.com/
- Site para catálogo e compras: https://pim4front.onrender.com/

O APK já contém esses endereços. Entre com sua conta de aluno da plataforma. Ele usa os dados do ambiente Render; nenhuma conta ou senha está embutida. Não exige computador nem emulador para se conectar.

Esta é uma compilação debug assinada com chave de desenvolvimento, destinada à demonstração acadêmica e instalação direta. Não é uma distribuição de loja. Para atualizar entre builds de demonstração, pode ser necessário desinstalar a versão anterior se a chave de desenvolvimento mudar.

`build-info.json` identifica a revisão e os endereços; `SHA256SUMS.txt` permite conferir a integridade do APK. Um build release com assinatura de distribuição continua exigindo a configuração de android/key.properties; essa proteção não foi removida.
